# Equal-Sign Repair AI-value harness — archived

This adult-authored synthetic CLI experiment was built under D-012 to compare a
compact deterministic classifier with a constrained OpenRouter model route.
The real-model route was never run. D-014 later dropped the product direction,
so **do not add an API key or spend model calls for this experiment**.

The code remains versioned as decision evidence. Its baseline-only result and
limitations are recorded in:

- `docs/prototypes/equal-sign-repair/ai-value-test-build-report.md`
- `docs/evidence/experiments/equal-sign-repair/ai-value-test-2026-09-13.md`

To rerun only the deterministic checks from the repository root:

```bash
./node_modules/.bin/tsx experiments/equal-sign-repair-ai-value/run.ts
```

Keep `OPENROUTER_API_KEY` unset. This experiment contains no learner data and
does not provide evidence of child learning, grade suitability or mastery.
