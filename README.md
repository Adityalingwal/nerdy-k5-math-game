# Nerdy AI Hackathon 2026

Working repository for a focused submission to Nerdy's AI Hackathon Challenge.

GitHub: https://github.com/Adityalingwal/nerdy-ai-hackathon-2026

Current direction: **K-5 Math Game**. The exact learner, math concept, mechanic,
and AI behavior are still being validated through bounded research.

Start with [docs/00-index.md](docs/00-index.md). It is the canonical navigation
page for product decisions, official-rule constraints, research, progress, and
evidence.

## Current phase

`Research -> scope -> learning loop -> prototype -> child-safe validation -> demo`

The goal is one polished, demonstrable learning loop, not a broad learning
platform.
