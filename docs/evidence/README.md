# Evidence directory

This directory stores internal synthetic test results, verification scripts,
text logs and a small set of useful screenshots. It contains no learner study
or learning-outcome evidence.

The automated Mission Forge and Equal-Sign Repair browser reviews produced
large, repetitive screenshot sets under `docs/evidence/prototypes/`. Those PNG
files remain available in the local working archive but are intentionally
excluded from Git history. Their verification scripts and text logs are
versioned so the checks can be inspected and rerun.

See `docs/evidence-register.md` for the status, source and limitations of every
recorded claim.
